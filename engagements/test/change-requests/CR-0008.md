## Notes

Allow users to interfere when Millhouse reject orders and override the Millhouse product order payload. This is applicable for ProductOfferingQualification and PorductOrder calls.
Millhouse orders rejections and failures will trigger the fallout management module, which will lookup the rejection/failure status and code and derive the desired action. Actions can be either:
open a manual fallout allowing the operators to retry with the option to override the Millhouse payload.
notify Shopfront to cancel the order and then wait for cancellation
