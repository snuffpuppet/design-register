## Notes

Expose GDA674 API to Shopfront allowing consumers to create (POST) and query (GET) geographicSite objects. The API should support the following capabilities:
Creating Depots/Locations with only with the standard TMF attributes
Creating Locations with includes the extended attributes
Creating Locations with reference to DSA
Updating Locations with reference to DSA
Query a specific Depot/Location with its Id.
Query Depots/Locations, filtering by their attributes
